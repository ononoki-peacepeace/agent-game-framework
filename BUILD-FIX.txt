Agent Game Framework v0.1.12 build hotfix

Usage:
1. Stop the currently running server with Ctrl+C.
2. Extract this ZIP into the project root (for example D:\game) and allow overwrite.
3. Run:
   npm run build
   npm start

Important: if `npm run build` fails, `npm start` can still launch an older existing `dist` directory. Only test the app after the build succeeds.
