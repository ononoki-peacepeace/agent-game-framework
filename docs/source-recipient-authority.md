# Source-owned speech recipients

`talkPerson` previously accepted a bound or ambiguous Planner `referent` before checking the original source or conversation context. A real but wrong model-supplied person could replace the sole person explicitly named by the player. It could also override an active pronoun referent or invent a recipient where several people genuinely remained ambiguous.

The existing contract resolver now prioritizes a uniquely named addressee in a directly evidenced single-clause recipient frame. A named discussion subject is not forced into that role: “向他询问林舟” resolves the preceding pronoun from existing public context, while “询问林舟他接下来的安排” binds Lin. The same existing pronoun binder handles a question containing a named topic, so a Planner cannot choose the topic as its recipient; without unique public context it stays ambiguous. Multi-clause role alignment retains its existing path. With several named people, a suggested recipient may still identify one of those source-authorized people; existing per-stage roles and genuine multi-person ambiguity behavior remain. Model referents remain a fallback when these source/context constraints do not determine the answer. This is a correction of binding authority within the existing open-action pipeline, not a new action vocabulary or execution route.

Baseline `source-recipient-authority-baseline.json`: four new product failures and six passing controls. The first nine-file regression passed 140 tests; subsequent role-review/adversarial cases exposed named-topic boundaries. All intermediate failed reports are retained. `source-recipient-role-final.json` passes nine files / 144 tests, including subject/addressee and missing-context controls, goal-contract dependencies, Semantic ownership, scene lanes and actual Core TALK execution. A rewritten Planner name no longer changes a directly source-owned receipt target; a persisted completed plan does not repeat speech. No NPC willingness, world facts, relationship rules or time costs were relaxed.

This does not establish arbitrary cross-sentence coreference, every audience-role interpretation, real-provider planning quality or human acceptance. Broad Semantic/Planner goal alignment and dynamic presence checks remain authoritative. No public schema/interface change is required; the contract module and regression tests are the implementation dependency.
