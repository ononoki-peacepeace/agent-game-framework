# 固定条件的验收细则 v1

本文是首次条件基线的一部分，细化原21个“部分完成”包的剩余条件。表中的场景是同一条件内的检查单，不再拆成新的计分项。所有场景均通过才能计该条件的0.625个百分点。没有证据记待验证；已知缺失记未满足；发现反例撤回已有通过状态。

各次验收先保存场景清单、输入、预期、源文件哈希和运行命令，再进行修复；复现失败及修复后结果都保留。跨世界条件使用已有世界中至少三种不同结构：含交易与移动、含人物对话与关系、含自主生活与背景事件。每种结构包含正常、歧义/缺失、世界拒绝、技术故障与重放边界；不能只换世界名称。若现有场景不足，条件保持开放，不以缩小样本宣告通过。真实模型及人工条件须保留授权和原始结果；离线 mock 不能替代它们。

|---|---|---|

| R6 | pending、后台 job、异步结果分别验证准备前中断、提交后未终结、重启恢复；仅继续未提交部分 | 独立子进程强杀覆盖准备前后、存档替换前后、终态前后；重启查询与存档凭据一致，不重复时间/RNG/资源 |
| R7 | 外部工作区的创建、文件写入、构建、安装、注册均有失败身份；每步前后失败可回收或明确安全停止 | 强杀构建及安装子进程后验证进程退出、工作区保留、注册状态、再次查询；嵌套失败必须有原始阶段与输出 |

| R10 | global/session 的创建、启停、删除分别验证原身份、删除后重启重放、变参拒绝、写前/后及终态故障；会话内容不跨重启恢复；HTTP 不谎称全局未改 | 范围移动每个存储边界前后故障、同ID竞争与重启均只有一个可识别权威；未证实提交必须停，不假称跨文件原子性 |
| A4 | 意图表达、纠错、准备与最终目标、被拒及部分完成逐类固定原句；完成只接受目标对应的 Core 证据 | 固定同一语料在授权的当前模型上跑全套，逐句验收目标、结果及是否该澄清，无未记录失败 |
| A5 | NPC、物品、地点、场景对象每类都测同名、别名、缺席与混合角色；不得由模型猜测消除真歧义 | 三种世界结构的固定绑定集全通过，实际落地对象与原文授权一致；不存在即不执行 |
| A6 | 跨句代词、话题/收件人、多个动作角色、焦点切换各有唯一与歧义样例，明确授权对象 | 三种世界结构中唯一对象不被过度澄清，歧义对象不猜测；后续实际动作与重放保持绑定 |
| A7 | if/else、不成立条件、依赖失败、嵌套/混合动作与中途改意图逐类明确哪些步骤应执行 | 固定组合语料正常与中断重启均逐步核对凭据、已完成和未执行；重复请求不再次消费资源 |
| A8 | 身体限制、距离、能力、地形、容器/临时物的前提变化各测满足与不满足，描写不能补造前提 | 三种世界结构的自由动作固定集，核对物理结果、时间/资源及游戏失败；技术修复不得把失败改成成功 |
| W4 | 睡眠、工作、休息、旅行及突发中断各测时间额度、位置和资源前提；不能重复或超额结算 | 每种世界结构连续模拟至少72小时，跨重启、时段切换与中断后计划可解释且能继续，不把重复空循环记行动 |
| W5 | 新事实、资源不足、位置变化、关系变化、重复失败各触发长期目标保留或有理由修订，而非直接丢弃 | 三种结构72小时加重启，逐角色核对目标、计划游标、阻塞原因、修订与完成证据，不重复执行旧步骤 |
| W6 | 体力/伤病、资源消耗/恢复、离开/到达与瞬时感知失效各有成对案例；前提只从当时事实派生 | 72小时并插入重启，核对位置、资源、身体和感知来源；未结算动作不得改变资源或让离屏感知持久化 |
| W7 | 至少三NPC链式互动，含记忆冲突、拒绝、独立事件及重复凭据；关系改变都有来源 | 三种结构72小时并跨重启；每次关系/记忆变化能回溯事件，私密不传播，Undo与重放不重复社会后果 |
| W8 | 背景事件至少覆盖产生、升级、解决及未解决；角色响应、玩家缺席与宏观后续都有因果依据 | 三种结构72小时模拟，无离屏泄漏、凭空完成或重复结算；不要求每次随机出现同一种事件 |
| N3 | 每种身体/发言复合场景包含成功、失败与未执行步骤；描写和凭据逐步对应、不漏关键结果 | 三种结构固定文本样例复核完整性及自然表达；事实与风格分别评价，不能只用测试数量代替文本质量 |
| N4 | 合法比喻、转述、感官限制、缺席者、物品状态各设合法与越权对照，保留误拒/误放原例 | 固定三种结构对照集全通过；合法句不因通用黑名单被拒，越权句不因修复放过 |
| N5 | 同一情境下不同人物、同一人物不同记忆/关系有固定对照；输出体现对应差异且不字面复读样本台词 | 授权真实模型跑固定多人物对话，记录人格、关系、记忆、自然度逐项人工判定，不用上下文注入测试冒充声线验收 |
| N6 | 容器内容、环境物、临时物、转交及消耗逐类测试描写前后；未存在物品不得成为可用资产 | 三种结构逐个比对描写、权威实体、持有者与后续实际使用；虚构与错误拒绝均保留为失败 |
| N7 | 位置、承诺、已发生事件、人物记忆与关系各设前后对照；叙述只表达角色可知事实 | 三种结构72小时跨重启固定回看点，逐段核验前述事实与人物表达，不用短期单元测试替代长期体验 |

这些最低覆盖要求用于约束关闭条件，不保证任意自然语言、任意模型或任意硬件永远成功。新增真实缺陷仍记录；原范围缺陷会使对应条件回退，新增范围风险保持独立，不扩大原分母。
