## 已取得的实际结果

- 修复服务重启后丢失请求内存索引、类型化 404 被当成暂时网络错误反复查询的问题。
- 恢复轮询有界、可取消；删除对应 marker 后 React 状态与轮询一起释放；不自动 POST 重放行动。
- 请求开始与终态写入辅助持久化索引，原 Receipt 仍是世界权威。缺少完整终态但找到提交证据时，只恢复已确认进度。
- 保留最终世界校验，复用 JsonStore 已校验的独立读取副本，移除没有迁移时的重复全量校验。
- 接触成功不再等于持续控制。控制须全部控制阶段成功；旧 Receipt 兼容读取，没有改写正式历史。
- 受控 NPC 可通过已有反应调用选择 Core `BREAK_FREE`。使用本人能力、对抗 RNG、状态校验和 Receipt；不保证挣脱，不自动离场，不重复推进世界时间。
- 环境危险尚无依据时，允许独立接触阶段结算；依赖环境的伤害阶段明确受阻，不消耗该阶段 RNG、不造成伤害、不推断环境安全。伪造来源仍拒绝。
- 单个即时 GoalSpec 尝试保留原句进入执行绑定，不再默认重复规划；复合、歧义、定时、纠错仍规划。它不提供“已完成”证书。
- 正式 GoalSpec 路径不再由旧句式检测器插入或删除条件。旧离线兼容入口仍保留原适配。
- 大地图、长人物资料不能优先挤掉相关人物的生命值、控制状态等查询依据。
- `save.read` 新增有限来源标签，便于区分 state/view、语义上下文、恢复和提交核对；没有删除审计记录。

## 剩余三项收口（2026-10-16）

### 1. 物证、真相和个人认知

找到并修复的断点：

- 锚定物品的证据曾按创建地点判断可发现性，物品被拿走后会失联。现在跟随真实实体和持有者；其他人物的背包不等于可查看的当前场景。
- Core `INSPECT` 原来只写“观察”，没有执行证据判定。现在通过现有 CheckSpec/RNG 按行动者本人判定已有可发现证据；无候选证据时不额外掷骰。
- NPC 调查发现写入自己的 observed knowledge，保留来源与时间，不自动获得整项真相，也不传播给第三人。
- 玩家已发现的信息通过只读 known_evidence 投影查询，不再完全依赖最近一段旁白；物证毁坏不抹除曾经获知的信息。
- 新增已有 inventory 模块的 `TRANSFER_ITEM`、`DAMAGE_ITEM`，并为 Freeform 增加可选 item_change 接线，共用物品状态修改函数。只有已登记、可接触、被授权的物品可发生权威持有、转移或损坏。普通背景物体不必因此全部实例化。
- 物品 condition 可选，旧档不必强制迁移。损毁的装备解除槽位占用，不能重新装备或通过再次损坏变回完好。
- 关联物证毁坏保留原始 event_ref，另外记录 destroyed_event_ref；新 Receipt 带世界时间，指向真实行动者、目标与判定。
- 拒绝同一非堆叠物品同时由多人持有、持有且仍放在场景、重复证据 ID，以及没有真实事件依据的因果证据注册。
- 修复预置真相实例化的约束旁路：旧 seed 文本包含约束，不再足以许可新结果丢弃该约束。没有修改正式真相。

验证覆盖发现→拿取→移动→转交→NPC 检查→损毁→重载；另用真实 JsonStore/GameService 验证同请求幂等与 Undo 恢复物品、证据、时间。损坏失败是正常判定，不改变物品状态。所有测试均在隔离世界。

### 2. 长期 NPC 与后台事件

确认并修复了绝对时间取模选人的公平性问题：固定跨度推进可能重复选择同几个 NPC。现在按持久化的 last_autonomous_at / last_daily_at 优先给等待最久者机会；失败也消耗一次调度机会，避免故障人物垄断后续预算。

没有提高模型调度频率或每轮调用上限。日常规则和 Core Action 仍不需要固定模型调用。既有深度调度仍按 180 游戏分钟时机运行，每轮最多 2 名；不是每名 NPC 每 180 分钟各调用一次。长跳时不补发无限历史调用。

NPC 的 TAKE / DROP 复用 actor-aware MOVE_ITEM；不会错误修改玩家背包。移动、调查和交谈仍使用现有 Core。公开动态路线进入现有 NPC 地图上下文，不引入另一套地图或模拟器。

隔离验证：12 名 NPC，3 组随机样本（0 / 0.47 / 0.99），各推进 9 日，12 名均获得机会，每次不超过 2 个深度决策。依自身目标行动者发生一次合法移动，留守者保持原位；既定后台事件自行启动和结束，未下达“触发剧情”命令。另验证 Provider 失败不垄断、Save/Reload 保留排队次序、Undo 恢复调度时间和个人状态、NPC 拾取不改玩家背包。

这是 Core 与模拟 Provider 的长期集成验证；不是“真实模型运行了 9 日”或“自主 NPC 社会完全模拟”的声明。是否移动仍取决于意愿、目标、路线和资格，未强制正式人物活动或提前触发正式事件。
