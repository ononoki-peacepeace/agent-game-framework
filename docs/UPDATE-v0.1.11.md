# v0.1.11 — Player Full-body + Automatic Avatar Crop

- 主角状态页现在和 NPC 一样可以上传 / 更换全身图，也可进入自己的完整人物详情。
- 头像与全身图继续独立保存：已有头像时，上传全身图不会覆盖头像。
- 当头像为空、首次上传全身图时，浏览器会在本地从全身图上部中央自动裁出 512×512 头像并上传，不调用 AI。
- 自动裁切是面向常规角色全身立绘的安全默认，不做不可靠的“通用人脸识别”。任意构图若自动结果不理想，可随时单独上传头像覆盖。
- 全身图仍保存在 `data/assets/visuals`，头像保存在 `data/assets/avatars`；Save 只保存资源 ID。
