# Runnable offline prose capture and anchored review

`node scripts/narrator-prose-benchmark.mjs` runs18 fixed cases from the existing four offline fixture files through the required isolated test wrapper. The fixed JSON lists each exact test name and five anchored review dimensions: voice, rhythm, perception, naturalness and continuity. Outputs are written to a new ignored `.agent-runtime/codex/prose-benchmark/<timestamp>/` directory; previous runs are never overwritten.

The three structures are existing town commerce/map, social/physical interaction, and sparse calendar/activity/background fixtures. Trade samples capture actual quantity, price, equipment and ordered purchase/equip; social samples retain actual physical failure/success, NPC-owned fixture utterances and observation; continuity samples distinguish full activity, pre-start interruption, one-minute interruption, actual background interruption and restarted replay. These are structural variants, not three unrelated production worlds. The early18-case ignored draft included two-person voice and changed-memory comparisons that this runnable baseline **does not implement**; the JSON explicitly keeps those gaps open.

The capture hook reads the fixture storage directly before/after the real `GameService.turn`, records public projections, new actual receipts and rendered text, and matches speech only to a persisted decision with the same NPC and utterance. It does not provide a narrator candidate or change an existing test assertion. Authored offline NPC decisions prove source/retention only; they cannot establish model voice quality. Repeated calls produce separate records, so replay and unchanged images remain inspectable. No production/private save is exported, no normal-provider call is authorized, and no rating is assigned automatically.

Every run saves source hashes before execution, original HEAD, test report/log, exact per-case JSON, a Markdown sample table and a blank review JSON. A run fails if the underlying tests fail/skip, a case has no actual capture, or a pinned input changes. Existing fallback snapshots remain the canonical factual regressions. The rubric requires all factual/knowledge hard gates and at least2/3 for each applicable quality dimension, with N/A explained. It cannot turn averaged style scores into a pass for an invented fact. Independent/human review is still a separate original gate.
