Parent `218559d`, product `a253d58`. Before repair, `performDeclaredActivity` applied full declared effects before running Core WAIT. The open-goal runner subsequently accepted `done`. Baseline: 5 failures, 2 full-duration controls. A4.2 was explicitly withdrawn.

The service still validates effects before execution, but applies them to the candidate only when Core reports the full declared duration. It preserves actual elapsed time, triggered events and foreground interruption in one existing atomic save, with a truthful unfinished narrative. No proportional payment or recovery rule is invented. The open-goal runner checks actual elapsed canonical time and stops immediately on interruption, without another model completion decision. A task at the exact end of the activity preserves the full reward. No save schema, Core settlement, request journal identity or public service return type changes; the shared service and affordance edits must be integrated together.
