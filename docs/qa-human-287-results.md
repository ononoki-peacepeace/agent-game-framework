## 实现：复用既有链路

- GoalSpec 与 Freeform 共用可选 `repetition` 契约：逐字 source_quote、明确秒数/未指定、单次间隔及明确终止模式（`while_executable` / `until_unsuccessful_result`）。普通未命中不等于失去执行能力；只有玩家明确要求单次结果不成功就停，才采用后者。只有一个即时、无额外起始依赖的目标可走保留原文的执行入口；开始条件和多步依赖不被删除。
- 已验证的语义约束由执行交接传给 Freeform，绑定模型不能静默丢弃时长与中止条件；显式秒数另作确定性核对。
- 现有 `executeAction` / `prepareCheck` / `resolveCheck` 逐次重新检查并结算，最多八次，不为每次调用模型；明确授权的失败即停、目标不可用、行动者不能继续、世界中断及预算限制可停止。
- 复用 `runtime.scene_seconds` 累计亚分钟时间，到整分钟才调用原有世界时钟及事件钩子，不根据 Token、网络或阅读耗时计时。秒数发生变化也有 `time` 证据。
- 保留每次真实 Check/Receipt，另有当前玩家动作的聚合回执。子回执随同一原子存档提交；请求恢复不重复掷骰或动作。预算/中断未完成明确时长时，返回部分进展，不冒充全部完成。
- Core 对抗骰承担即时抵抗；既有 NPC Agent 的有界反应仍在同一玩家动作中运行一次，而非每一拳分别调用。地图离场依然必须有合法移动结算。
- 已知前置条件受阻复用 `WorldBlockedError`，不再包装成内部安全结算失败。Schema/绑定错误继续保留技术故障类别。
